# EduNest LMS — Frontend (Client)

React + Vite frontend for the **EduNest Learning Management System**, a 5th Semester BCA (AI & DS) project by **Vachaspati Tiwari** and **Prerana Anand** at **Graphic Era Hill University, Haldwani**.

For full project documentation, features, setup instructions and API details, see the [root README](../README.md).

## Quick start

```bash
npm install
npm run dev
```

Runs at **http://localhost:5173**.

> Make sure the backend (`../Server`) is running on **http://localhost:5014** first.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint over the source |

## Tech

React 18 · Vite · React Router v6 · Redux Toolkit · Tailwind CSS · DaisyUI · Axios · Chart.js · React Icons · React Hot Toast
